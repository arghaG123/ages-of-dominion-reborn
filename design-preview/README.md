# Ages of Dominion design storyboard

Open index.html locally in a browser, or serve the repository as static files and open /design-preview/index.html. No installation, build, network, game server or image-generation job is required.

This is a **design proposal awaiting owner feedback**, not the game. It contains thirty visual section layouts. The right navigation chooses a view; on small screens that navigation becomes a horizontal strip. Inside-scene buttons only switch illustrative layouts or selected state. Nothing builds, fights, spends resources, alters balance or saves a campaign.

Use “Compare original” to see the immutable owner reference next to the proposal. “Reference proportions” preserves the primary portrait reference ratio. “Tall phone 424×933” and “Landscape” reveal responsive issues; the revised source container preserves image aspect and binds masks and transparent pad targets to that same crop. A static JPEG still cannot prove the future world's state-aware camera or exact layer geometry. Numbers and costs are illustrative. Art provenance and limitations are below every scene, outside the game frame.

Kingdom worlds currently use the supplied reference JPEG as an explicitly labeled appearance target, with source-registered localized baked-HUD masking and separate DOM controls. This is permitted for static design review only. The future renderer must independently layer terrain, seventeen real pads plus hall, structures, terrace, districts and walls. Iron/Future are composition concepts without supplied age-specific references. Version 1 was rejected by the owner. The revised Adventure/Tactical/Defense use coherent supplied appearance anchors with proposed UI; no flat drawn roads/river diagrams remain. They are static references, not independently assembled worlds or finished animation. No raster was edited and no new image was generated.

The six-slot Hero view retains Helmet/Chest/Weapon/Greaves/Shield/Ring. Shield/Ring currently use explicitly disclosed clipped windows from the owner Hero reference; independent assets remain missing. Eight classes are present; existing several portraits are armored reskins, explicitly a class-identity limitation. Army/Codex retain all eight neutral creature identities and four flying roles. Shared kingdom treasury is shown in defense; there is no invented temporary currency.
