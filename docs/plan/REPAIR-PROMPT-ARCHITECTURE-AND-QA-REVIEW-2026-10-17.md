## Architecture decisions and concrete executor solutions

**Mobile game HUD.** Keep the existing offline renderer and semantic input controls, but implement actual game-specific visual components. Default resources display four real symbols and amounts, with names/full values retained accessibly. Default roaming controls are recognizable medallions; selected context explains actions. Text remains for narrative, costs/prerequisites, tooltips, confirmation, errors and recovery where it serves play. Large text tiles do not become acceptable by hiding their words.

**Co-designed Kingdom ground/wall.** Yes: necessary generation can create the wall and ground as a coherent registered composition. It must support truthful phase selection and dynamic buildings. Start with source-bound guide/base/mask preparation, one correct family master, and matched states; reject drift or wrong physical fit before dependent extraction. Make forewall occlusion from the same painting at the same position. No full fake city behind hotspots, broad blur, moved cells, independent32scene drift or budget/routing shortcut. U08 supplies a concrete instantiated-request template and exact current geometry inputs.

**Release sequence.** Finish and verify the whole desktop game first, including actual visuals, natural journeys, storage/negative cases, responsive interaction and motion. The planner independently reviews that complete browser/source candidate before final packaging. Build the final artifact from the reviewed snapshot, then check identity/closure and proceed to already-authorized later mobile QA. No routine intermediate APK construction. Native-specific defects still get fixes/rebuild/rechecks as necessary; the sequence does not promise a defect-free first device run.

**Accountability.** The implementation AI owns repairs, source/consumer binding and current proof, and must continue every independent ready task. The planner owns architectural clarity, requirement consistency and independent returns. Exact external budget/access constraints remain honest scoped limits, never a false PASS or reason to stop unrelated work. Owner acceptance remains the owner's decision.
